Hideout Rebuild - Escape from Tarkov PvE hideout tracker

Open index.html in any browser. No install and no internet needed
(fonts fall back to system fonts when offline; wiki links need internet).

Your progress saves in that browser on that computer only.
Each person who opens the file tracks their own progress from zero.

The stash starts marked as level 4 (Edge of Darkness). On another
edition, open Build order > Built and press "Undo last level" on Stash.

Data: tarkov.dev PvE data. The date of the last update is shown at
the top of the page. Flea prices are 24-hour averages from that day.

Optional: on the Traders tab, "Choose Logs folder" reads your own game
logs (the Logs folder inside the game install folder) and ticks off
tasks the game recorded as completed. The files are read in your
browser only. Do not send your log files to anyone: they contain
account and network details.
